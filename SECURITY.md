# Security

Review skills and executable helpers before trusting this repository. Roles
inherit client permissions; project guidance is not a security sandbox. Keep
AppSecret, session keys, payment secrets and server credentials off the client.

For sensitive reports, use GitHub private vulnerability reporting if enabled:
https://github.com/houxin0010/Codex-Game-Studios/security/advisories/new
If unavailable, contact the maintainer through their GitHub profile without
posting exploit details or secrets publicly. No response-time SLA is promised.
