# Memory and session notes

No automatic persistent agent memory is enabled by this port. Update durable
memory only on the user's explicit request. Session checkpoints may be updated
within the authorized task and are ignored by Git. Do not write personal/global
memory merely because an upstream role carried memory: project metadata.

Prefer durable methods over transient absence. A fresh template will later gain
source, assets and tests; never store their current absence as a permanent fact.
Verify recalled file/config facts and state any stale evidence. Disclose authorized
note writes and their paths. See codex-runtime.md and context-management.md.
