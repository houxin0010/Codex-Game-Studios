# Quick start

Follow the bilingual root README. Invoke `$start` for a new game, `$setup-engine`
for Godot/Unity/Unreal, or `$setup-wechat` for native/Cocos/LayaAir/Unity mini games.
Then `$brainstorm`, `$create-stories`, `$dev-story` and `$story-done`.
Settings are resolved explicitly from project.local.yaml → project.yaml → legacy
fallback → rigor defaults. See config-resolution.md and codex-runtime.md.
