# Agent coordination

Directors own strategic decisions, leads coordinate departments, and specialists
own implementation domains. Consult peers without binding cross-domain decisions;
escalate conflicts to the shared lead/director and coordinate propagation with
the producer. The human's instruction decides scope and final product direction.

Use current Codex native subagent tools only when the user asks or an invoked
skill instructs delegation. Run independent read tasks in parallel within the
configured cap; wait for prerequisites and all requested outputs before dependent
phases. Own explicit, disjoint file paths for parallel writes. Do not recursively
spawn a department just to reproduce the organization chart. If subagents are
unavailable, work sequentially from the relevant role prompts and name the limit.

Return evidence, file references, completed checks and NOT ASSESSED items. A
blocked agent is reported, not silently skipped. The studio roles inherit the
parent model; see model-tiers.md. Runtime/API adaptations in codex-runtime.md
take precedence over inherited Claude workflow prose.
