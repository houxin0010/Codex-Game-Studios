# Setup requirements

Use a current local Codex client with project TOML custom agents and repo skills,
Git, Python 3.11+ (TOML validation), Bash and Node.js 18+ (example tests). Review
and trust the project with normal Codex controls, then start from its root.
No global configuration is edited. No permission bypass is recommended.
Invoke `$start`; for mini games invoke `$setup-wechat`. WeChat DevTools and a
registered mini-game AppID are required for previews and uploads. CLI commands
for WeChat require locally configured DevTools service access, not a repository
credential. See docs/wechat/README.md and codex-runtime.md.
